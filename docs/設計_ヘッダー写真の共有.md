# 設計：ヘッダー写真の共有（2.9・無料）

共有コードで参加した人に、旅行のヘッダー写真が出なかった（写真は端末の中にしか無く、
共有レコードにはファイル名しか載せていなかった）。ご要望から、写真も共有する。

## ルール

1. 1つの旅行に写真は1枚。**2.9 以降に誰かが写真を変えたら、全員その写真になる**（版 `set-…`）
2. 2.9 に上げた直後は、**自分で入れていた写真を勝手に置き換えない**
   - まだ誰の写真も載っていない旅行では、最初に同期した人の写真を載せる（版 `init-…`）
   - `init-` の写真は、写真を入れていない人にだけ出す。自分の写真がある人はそのまま
3. 写真を消しても、ほかの人の写真は消さない（載せ直さないだけ）
4. 自分で写真を変えてまだ送れていないあいだは、届いた写真で上書きしない

判断は `SharedCoverPhoto.uploadVersion` / `adoption`（純粋関数、テストあり）。

## データの持ち方

- 共有レコード（パブリックDB `SharedTravelPlan`）
  - `coverImage`（Asset）：長辺 1000px・JPEG に縮めた写真（1枚 100KB 前後）
  - `coverImageVersion`（String）：版
- 端末（UserDefaults）
  - `SharedCoverVersion_<planId>`：この端末が使っている（見た）版
  - `SharedCoverPending_<planId>`：写真を変えて、まだ載せていない
- 取り込んだ写真は、ほかの写真と同じく Documents に保存する（Pro なら iCloud にも預かる）

## 気をつけること

- 共有コードを知っている人は写真を見られる（旅行の中身と同じ場所に置くため）
- 共有レコードを取るたびに写真も一緒に降りてくる。通信を軽くするため 1000px に縮めている
- **Production に `coverImage` と `coverImageVersion` を反映してからリリースすること。**
  反映していないと、写真のある共有した旅行で共有レコードの保存そのものが失敗する
  （写真の無い旅行には影響しない）
