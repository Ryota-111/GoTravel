# リリースノート（App Store Connect 用）

「このバージョンの新機能」に貼る文面の下書き。
アプリ内の新機能お知らせ（`Helpers/WhatsNewManager.swift` の `WhatsNew.all`）と
内容を揃えること。

---

## 2.4

```
いつもTravoryをご利用いただきありがとうございます。

■ ご意見・ご要望を送れるようになりました
アプリ内の「ヘルプ・サポート」から、欲しい機能や気になった点をそのままお送りいただけるようになりました。いただいた声には必ず目を通し、改善に活かしています。「こんな機能が欲しい」「ここが使いにくい」など、どんなことでもお気軽にお寄せください。

■ 共有コードの不具合を修正
共有コードが相手に届かず、参加できないことがある問題を修正しました。コードは発行が完了してから表示されるようになり、iCloudにサインインしていない場合はその旨をお知らせします。

■ 海外でも時刻が正しく表示されます
現地の時間帯に合わせて予定の時刻を表示するようになりました。

■ ロック画面ウィジェットの更新を改善
予定の時間を過ぎたら次の予定へ自動で切り替わるようになりました。

Travoryは一人で開発しています。皆さんと一緒に、もっと使いやすいアプリにしていきたいと思っています。ご要望をお待ちしています。
```

---

## 書くときの方針

- **要望を歓迎していることを毎回入れる。** 一度書いただけでは伝わらない
- 不具合修正は「何が起きていたか」を具体的に書く。
  「軽微な不具合を修正」だけだと、同じ症状で困っている人が
  自分の問題が直ったのか判断できない
- 修正のきっかけが問い合わせだった場合、それが伝わる書き方にすると
  「送れば直る」と実感してもらえる

## 伝える場所の一覧

| 場所 | 届く相手 | 更新のタイミング |
|---|---|---|
| App Store リリースノート | アップデートする人（読む人は一部） | リリースごと |
| アプリ内の新機能お知らせ | アップデートした全員 | `WhatsNew.all` に追記 |
| ヘルプ・サポート画面の説明文 | 自分で見に来た人 | 随時 |
| App Store の説明文 | 新規インストール検討中の人 | 大きな変更時 |
| サポートページ（GitHub Pages） | 問い合わせ前に見る人 | 随時 |
