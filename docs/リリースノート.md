## 2.4

```
いつもTravoryをご利用いただきありがとうございます。

■ 実際に使った金額を記録できるようになりました
予定をタップして「実際に使った金額」を入力すると、予算との差額がその場で分かります。予算サマリーでは旅行全体の予算と実績、超過額・節約額をまとめて確認できます。ご要望をいただいて追加した機能です。

■ 登録できる場所が大きく増えました
場所の検索が画面に表示中の範囲だけを対象にしていたため、少し離れた場所が見つからない状態でした。全国から探せるように修正し、あわせて住所でも検索できるようにしました。また、地図を長押しすると、検索に出てこない場所（ご友人のお宅や地図に載っていないお店など）もその場で登録できます。ご指摘をいただき修正いたしました。

■ 割り勘の人数を自由に変えられます
これまでは共有しているメンバーの人数で固定されていましたが、予算サマリーから自由に増減できるようになりました。アプリを使っていない同行者がいる場合や、共有していない旅行でも割り勘を計算できます。

■ ご意見・ご要望を送れるようになりました
アプリ内の「ヘルプ・サポート」から、欲しい機能や気になった点をそのままお送りいただけるようになりました。いただいた声には必ず目を通し、改善に活かしています。「こんな機能が欲しい」「ここが使いにくい」など、どんなことでもお気軽にお寄せください。

■ アプリの色を変えられるのをご存じですか
「プロフィール」→「アプリ設定」から、アプリ全体の配色を選べます。白黒やパステルピンクもご用意しています。意外と知られていない機能でしたので、はじめて使う方には最初にご案内するようにしました。

■ 天気が日本語で表示されます
「Mostly Cloudy」のような英語表記を、「くもり時々晴れ」のように日本語で表示するようにしました。

■ 追加しやすくしました
「旅行計画」「予定計画」は見出しの横に、「場所保存」は画面の右下に追加ボタンを置きました。件数が増えても、一番下までスクロールせずに追加できます。マップを表示したままでも追加できます。

■ ロック画面ウィジェットの切り替えを調整しました
旅行中のタイムテーブルが、予定の時刻から5分後に次の予定へ切り替わるようになりました。

■ 共有コードの不具合を修正
共有コードが相手に届かず、参加できないことがある問題を修正しました。コードは発行が完了してから表示されるようになり、iCloudにサインインしていない場合はその旨をお知らせします。共有コードから、見間違えやすい「O」と「I」を使わないようにしました。

■ 海外でも時刻が正しく表示されます
現地の時間帯に合わせて予定の時刻を表示するようになりました。

Travoryは一人で開発しています。皆さんと一緒に、もっと使いやすいアプリにしていきたいと思っています。ご要望をお待ちしています。
```

## 書くときの方針

- **要望を歓迎していることを毎回入れる。** 一度書いただけでは伝わらない
- 不具合修正は「何が起きていたか」を具体的に書く。
  「軽微な不具合を修正」だけだと、同じ症状で困っている人が
  自分の問題が直ったのか判断できない
- 修正のきっかけが問い合わせだった場合、それが伝わる書き方にすると
  「送れば直る」と実感してもらえる
