# リリースノート（App Store Connect 用）

「このバージョンの新機能」に貼る文面の下書き。
アプリ内の新機能お知らせ（`Helpers/WhatsNewManager.swift` の `WhatsNew.all`）と

## 2.4

```
いつもTravoryをご利用いただきありがとうございます。

■ 実際に使った金額を記録できるようになりました
予定をタップして「実際に使った金額」を入力すると、予算との差額がその場で分かります。予算サマリーでは旅行全体の予算と実績、超過額・節約額をまとめて確認できます。ご要望をいただいて追加した機能です。

■ 登録できる場所が大きく増えました
場所の検索が画面に表示中の範囲だけを対象にしていたため、少し離れた場所が見つからない状態でした。全国から探せるように修正し、あわせて住所でも検索できるようにしました。また、地図を長押しすると、検索に出てこない場所（ご友人のお宅や地図に載っていないお店など）もその場で登録できます。ご指摘をいただき修正いたしました。

■ 割り勘の人数を自由に変えられます
これまでは共有しているメンバーの人数で固定されていましたが、予算サマリーから自由に増減できるようになりました。アプリを使っていない同行者がいる場合や、共有していない旅行でも割り勘を計算できます。

■ ご意見・ご要望を送れるようになりました
アプリ内の「ヘルプ・サポート」から、欲しい機能や気になった点をそのままお送りいただけるようになりました。いただいた声には必ず目を通し、改善に活かしています。「こんな機能が欲しい」「ここが使いにくい」など、どんなことでもお気軽にお寄せください。

■ アプリの色を変えられるのをご存じですか
「プロフィール」→「アプリ設定」から、アプリ全体の配色を選べます。白黒やパステルピンクもご用意しています。意外と知られていない機能でしたので、はじめて使う方には最初にご案内するようにしました。

■ 天気が日本語で表示されます
「Mostly Cloudy」のような英語表記を、「くもり時々晴れ」のように日本語で表示するようにしました。

■ 追加しやすくしました
「旅行計画」「予定計画」は見出しの横に、「場所保存」は画面の右下に追加ボタンを置きました。件数が増えても、一番下までスクロールせずに追加できます。マップを表示したままでも追加できます。

■ ロック画面ウィジェットの切り替えを調整しました
旅行中のタイムテーブルが、予定の時刻から5分後に次の予定へ切り替わるようになりました。

■ 共有コードの不具合を修正
共有コードが相手に届かず、参加できないことがある問題を修正しました。コードは発行が完了してから表示されるようになり、iCloudが利用できない状態（サインインしていない・規約への同意が保留になっているなど）の場合は、その旨をお知らせします。共有コードから、見間違えやすい「O」と「I」を使わないようにしました。

■ 海外でも時刻が正しく表示されます
現地の時間帯に合わせて予定の時刻を表示するようになりました。

Travoryは一人で開発しています。皆さんと一緒に、もっと使いやすいアプリにしていきたいと思っています。ご要望をお待ちしています。
```

## 2.6

```
いつもTravoryをご利用いただきありがとうございます。

■ タグで予定を仕分けられます
「仕事」「遊び」など、自由に作ったタグで予定を分けられるようになりました。一覧をタグで絞り込めるので、探している予定にすぐたどり着けます。カレンダーに出る点も、タグの色になります。

■ 通知のタイミングを選べます
「1週間前」「前日の夜」「1時間前」など、鳴らすタイミングを予定ごとに選べるようになりました。よく使う組み合わせは、種別ごとの初期設定として保存できます。これまでは入れるか消すかしかなく、選んだ内容も残りませんでした。

■ お土産リストとやりたいことリストを追加しました
旅行計画の「リスト」から、持ち物・お土産・やりたいことを切り替えられます。お土産には「誰に」を書いておけるので、お店で迷いません。旅行を共有している場合、やりたいことは同行者と一緒に書き足せます。持ち物とお土産はご自身にだけ見えるので、同行者へのお土産も安心して書けます。ご要望をいただいて追加しました。

■ 持ち物を前の旅行から持ってこられます
「前の旅行から」を押すと、以前の旅行の持ち物リストをそのまま取り込めます。チェックは外した状態で入り、同じ名前のものは重ねて追加しません。あわせて「よく使う持ち物」の候補も、ご自身で追加・削除・並べ替えができるようになりました。一度整えれば、次の旅行からもそのままお使いいただけます。ご要望をいただいて追加しました。

■ 画像に実際に使った金額が出るようになりました
旅行の記録を画像やテキストで書き出すとき、実際に使った金額を記録していればそちらを表示します。まだ記録していない項目は、これまでどおり予定の金額が出ます。旅行が終わったあとの記録として残していただけます。ご要望をいただいて追加しました。

■ 保存した場所をそのまま検索できます
場所の詳細から、その場所の名前でネット検索できるようになりました。営業時間や口コミを調べるのに、名前をコピーしてブラウザに貼り直す手間が要りません。

■ 地図に現在地が表示されない不具合を修正
マップで現在地の青い点が出ていませんでした。修正しています。あわせて、使っていない「常に許可」の位置情報の項目を削除し、実際の用途に合わせて説明文を書き直しました。位置情報を継続的に記録することはありません。

■ やることリストが引き継げるようになりました
これまで、やることリストは端末の中だけに保存していたため、アプリを入れ直すと消えてしまっていました。他のデータと同じようにiCloudで同期されるようになり、機種を変えてもそのまま残ります。ご不便をおかけして申し訳ありませんでした。無料でお使いいただけます。

■ 消したはずの旅行計画が戻ってくる不具合を修正
アプリを削除して入れ直すと、以前に削除した旅行計画が復活してしまうことがありました。古い保存先にデータが残っていたことが原因です。修正しました。

■ 写真をiCloudでお預かりします（Travory Pro）
これまで写真は端末の中だけにあり、機種変更やアプリの入れ直しで消えてしまっていました。旅行のカバー写真・保存した場所の写真・アルバムの写真を、お客様ご自身のiCloudにも保管します。開発者が写真を見ることはできません。

■ テーマが14種類増えました（Travory Pro）
色だけでなく、書体や角の丸み、カードの作りまで変わります。買い切りで、これから増えるぶんも含まれます。桜・瀬戸内・紅葉・雪国は、旬のあいだ購入なしでお使いいただけます。プロフィールの「Travory Pro」から、それぞれの見え方をご覧いただけます。旅行計画・予定・場所の保存・アルバム・共有・やることリストは、これまでどおり無料です。

■ 旅行中の天気が日ごとに出ます
複数日の旅行で、1日目・2日目…とそれぞれの日の天気を並べるようにしました。旅行中なのに「10日前になると表示されます」と出てしまう問題も直しています。

■ 場所まわりを使いやすくしました
訪問場所を先に登録しなくても、タイムスケジュールを追加するときにその場で場所を選べます。登録した場所が複数あるときは、経路案内の行き先を選べるようになりました。

■ 日常の予定に終わる時刻を入れられます
始まりだけでなく、終わりの時刻も設定できるようになりました。

■ 表示まわりの修正
おでかけの詳細・編集画面を、余白と区切り線で見やすくしました。ダークモードの背景が真っ黒で境目が分かりにくかったため、少し明るい色に変えました。iPadで画面の中身が左の細い列に詰め込まれてしまう問題も直しています。

Travoryは一人で開発しています。皆さんと一緒に、もっと使いやすいアプリにしていきたいと思っています。ご要望をお待ちしています。
```

## 書くときの方針

- **要望を歓迎していることを毎回入れる。** 一度書いただけでは伝わらない
- 不具合修正は「何が起きていたか」を具体的に書く。
  「軽微な不具合を修正」だけだと、同じ症状で困っている人が
  自分の問題が直ったのか判断できない
- 修正のきっかけが問い合わせだった場合、それが伝わる書き方にすると
  「送れば直る」と実感してもらえる
