# 設計：旅行のメモ帳（2.9）

旅行ごとに、自由な文章を1枚書けるメモ帳。リストのタブの「メモ」で開く。
「既存のリストに加えて、まとまった文章を書き留めたい」というご要望から（2026年10月）。

## 決めたこと

- 1枚の自由な文章（見出しで分けない）
- 共有した旅行では、全員が見て書ける（「やりたいこと」と同じ扱い）
- 書き終えたとき（キーボードを閉じたとき・画面を離れたとき）にまとめて保存する。1文字ごとには保存しない

## データの持ち方

- `TravelPlan.memo`（String?）
- Core Data：`TravelPlanEntity.memoText`（String、任意）
- 共有レコード（パブリックDB）：`SharedTravelPlan.memoText`（String）

ほかのデータ（持ち物の配列など）の中に間借りはしない。古いバージョンのアプリが知らない種類の
持ち物を読むと、持ち物の配列を丸ごと読めなくなり、共有では全員の持ち物を消すおそれがあるため。

## 共有での突き合わせ

1枚の文章なので混ぜられない。前回そろえたときから**書き換えた側を採る**。
両方が書き換えていたら新しいほうを採る（`SharedPlanMerge.mergeValue`）。

## リリース前に必要なこと（Production への反映）

**反映しないままリリースすると、共有した旅行でメモを書いたときに共有レコードの保存が失敗する。**
（被害を小さくするため、メモを書いた計画でだけ `memoText` を送るようにしてある）

1. Core Data（プライベートDB）
   - `CoreDataManager.swift` の `initializesCloudKitSchemaOnLaunch` を true にして、実機でデバッグ実行
   - CloudKit Console の Development で `CD_TravelPlanEntity` に `CD_memoText` ができたのを確かめる
   - false に戻す
2. 共有レコード（パブリックDB）
   - 実機で共有した旅行のメモ帳に何か書いて閉じる（Development に `SharedTravelPlan.memoText` ができる）
3. CloudKit Console で Deploy Schema Changes（`CD_memoText` と `memoText` が並ぶことを確かめる）
