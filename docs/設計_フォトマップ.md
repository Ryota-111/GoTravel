# 日本全国フォトマップ：複数作る・1つの県に複数枚

2026年9月の Feedback（42AA58C3）への対応。

> 日本全国フォトマップを、複数つくれるようにしてほしいです！
> また、一つの県に何枚も写真を保存できるようにしてほしいです

---

## 1. 2.7 までの作り

| 項目 | 置き場所 |
|---|---|
| フォトマップそのもの | 種類が `.japan` のアルバム1つ（`AlbumEntity`、既定アルバムで削除不可） |
| 写真のファイル | `Documents/JapanPhotos/<県>.jpg`（県ごとに1枚） |
| 写真のある県の一覧 | `UserDefaults` の `JapanPhotoPrefectures` |
| 写真の iCloud 保管 | Travory Pro のときだけ `PhotoSyncService`（`.japanPhotos`） |

困っていたこと:
- 県ごとに1枚しか持てない
- フォトマップは1つだけ
- **県の一覧が `UserDefaults` にあり同期されない。** 入れ直すと、Pro で写真を預けていても地図が空に戻り得た

---

## 2. 方針：アルバムの入れ物をそのまま使う

**CloudKit のスキーマは変えない。** 新しいエンティティも項目も足さない。

- **フォトマップ＝種類 `.japan` のアルバム。** 何個でも作れる（2つ目以降は Travory Pro）
- 写真の一覧は、アルバムの既存の `photoFileNames`（JSON）に並べる
- **ファイル名に県を含める：** `<県>__<UUID>.jpg`（例 `tokyo__1F2E….jpg`）。
  2.7 までの `<県>.jpg` もそのまま読める
- **県ごとの並びの先頭が代表写真。** 地図の県の形に切り抜いて出すのはこれ
- 写真のファイルは今までどおり `Documents/JapanPhotos/`、iCloud 保管も `.japanPhotos`（Pro）

一覧が Core Data に乗るので、**どの県にどの写真があるかは無料でも iCloud で同期される**
（写真そのものの同期は Pro のまま）。

### 上限

1つの県に **30枚** まで。端末の容量と同期の量を抑えるため。

### 無料と Pro

| | 無料 | Pro |
|---|---|---|
| 既定のフォトマップ（1つ目） | ✅ | ✅ |
| 2つ目以降のフォトマップ | ❌（作ろうとすると Pro の案内） | ✅ |
| 1つの県に複数枚 | ✅ | ✅ |
| 写真の iCloud 保管 | ❌ | ✅ |

Pro をやめた（返金など）あとも、作ったフォトマップは消さない。見る・写真を足す・消すはできる。
新しく作れないだけにする（消すと、払ったあとに作ったものが消えることになるため）。

---

## 3. 2.7 までのデータの移し替え

初回起動時に1回だけ、`UserDefaults` の県の一覧を既定のフォトマップの `photoFileNames` に移す。

- 移すのは `<県>.jpg` のファイル名。ファイルは動かさない（名前もそのまま）
- 既定のフォトマップに既に写真がある場合（別の端末で移し替え済みで同期されてきたなど）は、
  **足し合わせる**（重複は除く）。片方で上書きすると、もう片方の端末の写真が消えるため
- 済んだら `JapanPhotoMapMigrated_v1` を立てる（端末に1つ。2.7 までの一覧が端末ごとなので）。`UserDefaults` の一覧は念のため残す
- 移し替える前（アルバムの画面を一度も開いていない）でもウィジェットの県の数がずれないよう、
  それまでは2.7 までの一覧も足して数える

## 4. 画面

### アルバム一覧
- フォトマップごとにカード。カードの写真は、そのフォトマップの最近の写真
- アルバムの作成画面の種類に「日本全国フォトマップ」を足す。
  既定のフォトマップがあって Pro でなければ、選ぶと Pro の案内を出す
- 2つ目以降のフォトマップは、他のアルバムと同じく削除できる（既定のものは削除不可）

### フォトマップ
- 見出しはそのフォトマップの名前（アルバムの編集で変えられる）
- 地図と都道府県一覧は今までどおり。県には代表写真を切り抜いて出す
- 都道府県一覧のカードに、2枚以上あれば枚数を添える
- 統計の「登録済み」は写真のある県の数

### 県の写真（県を押したとき）
- その県の写真を格子で並べる。先頭に「代表」の印
- 「写真を追加」：まとめて選べる（残りの枚数まで）
- 写真を押すと大きく出し、「代表にする」「削除」
- 写真が無い県では、最初の写真を足した時点で地図が埋まる

## 6. 気をつけること

- 旧バージョン（2.7 以前）の端末は、フォトマップを1つしか知らない。
  2つ目以降は普通のアルバムとして開こうとし、写真が見えない（`JapanPhotos` を見ないため）。
  全員が上がれば解消
- 旧バージョンの端末は `UserDefaults` の一覧で地図を描くので、新しく足した写真
  （`<県>__<UUID>.jpg`）は旧バージョンの地図には出ない
