# 共有した旅行計画：メンバーごとの時間軸

2026年9月の Feedback（AE00AB41）への対応。**設計のみ。未着手。**

> 旅行プランのタイムスケジュールで、複数人共有の場合、個々人の時間軸も追加できるようになったら嬉しい。
> 例）出発地が異なり現地集合の場合のそれぞれの移動時間が見れる

---

## 1. 今の作り

- 共有メンバーは ID（`sharedWith`）しか持っていない。共有画面でも ID を短くして見せているだけ
- 予定（`ScheduleItem`）は計画に1本の時間軸で並ぶ。誰の予定かは持っていない

**「誰の予定か」を出すには、まずメンバーの名前が要る。**

---

## 2. 方針

### 2-1. メンバーの表示名

- 各自が、参加したときと同期のときに、自分の表示名を共有レコードに書く
- **パブリックDBの `SharedTravelPlan` に項目を1つ足す**（例 `memberNamesJSON`：`{userId: 表示名}`）。
  → **Production へのスキーマ反映が1回要る**（`docs/共有機能.md` の手順）
- 端末側の `TravelPlan` にも持たせる（JSON の中に置けば Core Data のスキーマは変えずに済む）

**要決定：** 表示名はプロフィールの名前をそのまま使うか、旅行ごとに付けられるようにするか
（「父」「さくら」など、旅行の仲間内の呼び方にしたい場合がある）。

### 2-2. 予定に「参加する人」

- `ScheduleItem.participantIds: [String]?`。**空（nil）なら全員**
- 予定の追加・編集に「全員 / 〇〇 / △△」の選択
- 予定の JSON の中の項目なので、Core Data のスキーマ変更は無い
- 共有の3方向マージは予定単位で比べているので、そのまま効く

### 2-3. 時間軸の見せ方

共有中の計画だけ、日程タブの上に「全員 / 自分 / 〇〇」の切り替え。

| 見方 | 出すもの |
|---|---|
| 全員 | すべての予定。全員のものでない予定には小さく名前を添える |
| 自分 | 全員の予定＋自分の予定（自分の移動と集合時刻が一目で分かる） |
| 〇〇 | 全員の予定＋〇〇の予定 |

- 集合は「全員」の予定として入れれば、どの見方でも出る
- 時差対応（`ScheduleClock`）と組み合わさる：出発地の違うメンバーは、それぞれの時計で入れられる

### 2-4. やらないこと

- **メンバーごとに列を横に並べる形。** iPhone の幅では読めなくなる
- 「参加する人」を持ち物のように**相手から隠す**こと。移動の予定は同行者が知っていてよい

---

## 3. 気をつけること

- 旧バージョンの端末が予定を編集すると `participantIds` が消え、全員の予定に戻る
  （時差対応の `timeZoneIdentifier` と同じ性質）
- 表示名が書かれていないメンバー（旧バージョンのまま）は、今までどおり ID を短くして出す

---

## 4. 進め方（案）

1. 表示名（パブリックDBの項目追加とスキーマ反映）
2. 予定の「参加する人」と、編集画面の選択
3. 日程タブの切り替えと、名前の添え書き
